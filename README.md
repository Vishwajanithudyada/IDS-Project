  Python Network Intrusion Detection System (IDS)

A real-time Network Intrusion Detection System built with Python, Flask, and Scapy featuring a live web dashboard.

  Features

- 📦 Real-time packet capture
- 🔍 Port Scan Detection
- 💥 DDoS Attack Detection  
- 🌊 SYN Flood Detection
- 📡 ICMP Flood Detection
- 📊 Live Web Dashboard (Sinhala UI)
- 🚨 Real-time Security Alerts
- 📈 Live Traffic Charts

  Technologies

- Python 3.10+
- Flask (Web Dashboard)
- Scapy (Packet Capture)
- JavaScript (Charts)
- HTML/CSS (Dashboard UI)

  Installation

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/IDS-Project.git
cd IDS-Project

# Create virtual environment
python -m venv venv
venv\Scripts\activate  # Windows
source venv/bin/activate  # Linux

# Install dependencies
pip install -r requirements.txt
```

  Run

```bash
python app.py
```

Open browser: `http://127.0.0.1:5000`

  Requirements

- Windows: Run as Administrator
- Install [Npcap](https://npcap.com) for Windows
